平台能力

能力地图

以下按决策与实施团队最常追问的主题组织，便于对照现有架构评估。

Skills 驱动智能员工

将业务能力沉淀为 Skills，由智能员工组合调用。避免脆弱、难维护的手搭工作流，使行为可复用、可评审、可版本管理。

RAG 知识库

企业文档与制度进入可检索知识层，支撑专业问答、营销话术与运维知识引用，降低幻觉风险对业务的影响。

MCP / CLI / API 连接器

通过标准协议与接口对接内部系统、工具与脚本环境，让智能体进入真实业务闭环，而非停留在对话层。

Automation

将可重复任务自动化执行，与智能员工协同，覆盖值守、批处理与流程接力等场景。

多租户权限

面向集团与多法人、多部门部署：租户隔离、角色授权，满足银行与大型企业的组织边界。

审核中心

对关键动作与发布进行人工或策略审核，把「能做」与「允许做」分开治理。

Skill 安全扫描

在 Skills 进入生产前进行安全扫描，识别高风险能力与不当调用模式。

审计与沙箱

操作可追溯；敏感执行可在沙箱中隔离验证，符合金融场景对留痕与可控试错的要求。

浏览器插件 & WPS 插件

嵌入员工日常办公入口，减少切换成本，让智能体出现在真实工作界面中。

微信通道

通过企业常用即时通道触达用户，适合通知、轻问询与移动场景衔接。

可信站点非侵入集成

在已信任的业务站点以非侵入方式集成能力，降低改造存量系统的阻力。

入驻智能体（Dify / FastGPT / HiAgent）

支持基于 Dify、FastGPT、HiAgent 等构建的智能体入驻与纳入治理，保护既有投入、统一运营界面。
