产品能力

企业级智能体平台

以 Skills 为核心构建可治理的智能员工运行时——覆盖知识、连接、自动化、权限与安全，面向对公与银行 IT 的交付标准。

Agent

像搭积木一样，构建你的智能体

在 Noesis 中无需编写繁琐的工作流，围绕业务目标配置智能体即可。底层多智能体架构让每次会话由最适合的智能体接力完成。

  • 可视化创建、测试与发布，管理智能体全生命周期
  • 灵活配置提示词、模型、计划模式、上下文与错误纠正
  • 支持传统聊天型、外部接入与企业定制智能体
  • 一键发布到个人助手、浏览器插件、WPS 插件、IM 与 API
RAG

企业级知识库，让 AI 说「有依据的话」

先进 RAG 设计带来更高的检索质量，完善的权限体系支撑企业内部知识安全共享，回答可溯源、可验证。

  • 多格式文档上传，构建企业专属知识库
  • 知识库细粒度权限设置，支撑企业内部协作
  • 召回测试与效果调优，检索质量可视化
  • 支持 Dify 对接，复用既有知识资产
Skills

用最小成本，把企业业务接入 AI

只要会写 Skill 和调用工具，就能完成业务 AI 接入。系统后台整体采用多智能体架构，边写边用、持续迭代。

  • 创建、编辑、调试与发布 Skill，配套环境变量与工具绑定
  • 历史版本比对与灰度覆盖，变更可回溯
  • 技能市场支持技能的发现、安装与共享
  • 与智能体配合，快速覆盖企业高频业务场景
连接器与自动化

连接外部系统，让智能自动运转

通过连接器打通 MCP、CLI、OAuth、HTTP 等外部能力，再以定时任务与对话编排让 AI 持续作业。

  • MCP / CLI / OAuth / HTTP 多种方式接入外部能力
  • 定时任务：按计划自动运行智能体会话
  • 对话设置：用自然语言直接编排自动化任务
  • 审核中心统一管理资源发布，发布流程可控可追责
